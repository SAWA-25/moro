# 人生拟（原生活拟/存钱罐）完善实现计划

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 按截图要求完善并丰富 `AppID.Bank` 对应的人生拟 APP：保留并改名，补齐模拟人生时间、Boss 直聘式求职、店铺经营、同花顺式投资、公司运营、借款、账本自动入账等功能，并让每个模块尽量完整模仿市面对应 app 的核心体验。

**Architecture:** 现有 `apps/BankApp.tsx` 已经把“生活拟”实现成 `人生 / 求职 / 经营 / 投资 / 公司 / 借款 / 账本` 七个 tab，核心状态在 `utils/bankLife.ts`，类型在 `types.ts`，账本联动在 `utils/bankLedger.ts` 与 `utils/db.ts`。本次应在现有实现上做“产品级补完”：重命名、扩展数据模型、增强 UI/交互、补充测试，不重写整套 App。

**Tech Stack:** React + TypeScript + Vite + IndexedDB；包管理器 pnpm；验证命令：`pnpm run test:run`、`pnpm run build`。

## 截图需求转写

OCR 提取到的明确需求如下：

- 存钱罐 APP 更改 APP 名字。
- 增加模拟人生功能。
- 模拟人生时间系统，参考模拟人生游戏。
- 用户可手动跳转下一天。
- 一般情况下工资一个月一结，除非是日结兼职岗位，在岗位对应的发薪日给用户工资/金钱。
- 增加打工求职功能，参考 Boss 直聘 APP。
- 岗位有专门介绍，可能会有黑心岗位，参考现实社会。
- 用户可选择应聘岗位，先选择大致分类，AI 判断用户是否可以应聘该岗位。
- 岗位包括不限于：保洁、餐厅服务员、程序员、保安；各个岗位都有，薪资不一。
- 原店铺功能并入模拟人生功能，仅为赚钱的其中一种赚钱模式。
- 店铺功能需用户有开店资本，至少 1w 才能解锁。
- 经营界面并入店铺功能。
- 增加股票投资功能，参考同花顺 APP。
- 增加公司运营功能，需用户先获得开公司的起步资金至少 10w 才能开公司。
- 用户可选择公司方向，自定义公司昵称。
- 解决公司日常事务。
- 增加借款功能。
- 可选择向银行、正规渠道、高利贷借款。
- 账本：用户发薪日薪资自动计入；用户在其他 APP 消费自动计入。
- 附加用户要求：除了修改 APP 名称，所有功能都要；每一个功能都要完整模仿市面上的对应 app。

## Risks / Tradeoffs

- “完整模仿市面 app”范围很大，建议优先模仿核心信息架构和交互，不复制品牌名、Logo 或受保护 UI 素材。
- 现有 `BankApp.tsx` 已超过 2500 行，继续堆功能会变难维护；若实现中改动很大，建议后续拆成 `apps/bank/LifeHome.tsx`、`JobBoard.tsx`、`InvestBoard.tsx` 等子组件。
- 账本联动依赖 `adjustUserBalance` 元数据，必须审计调用链，不能只改人生拟内部。
- 股票与借款均为虚拟模拟，不应使用真实金融建议文案；UI 可像行情软件，但需要保留虚拟/模拟语义。
